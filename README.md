# Console Mode

MPL-2.0 source for the **Console Mode** launcher frontend (MiSTer FPGA).

These files descend from [simplermenu_plus](https://github.com/rg35xx-cfw/simplermenu_plus)
(MPL-2.0) and remain under MPL-2.0. Per-file terms are in each file's SPDX header.

## Scope

This repository holds the MPL-covered portion of the frontend. The remainder of the
application (original Retro Remake code) is separately licensed and is not included
here, so this tree does not build on its own: it is the corresponding source for the
MPL-licensed files, published per MPL-2.0 section 3.

## Layout

- `src/` - MPL-licensed implementation files
- `include/` - MPL-licensed headers
